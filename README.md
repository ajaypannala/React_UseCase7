# React Product Management Dashboard

Frontend-only beginner React dashboard built with:

- React + Vite
- JavaScript
- Tailwind CSS
- React Router
- React Context API for authentication
- Zustand for product and cart state
- localStorage

## Run

```bash
npm install
npm run dev
```

No backend is required.

## Features

- Home page
- Register/Login
- Frontend authentication
- User/Admin roles
- Protected routes
- Admin-only Users page
- Authentication managed with React Context
- Product catalog and cart state managed with Zustand
- Product catalog loaded from the DummyJSON products API
- Shopping cart with quantity and stock limits
- Profile page
- localStorage persistence for users/authentication
